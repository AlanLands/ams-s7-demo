6:45 – 7:30 · Getting better — the admin panel. The operator's side; delivery users never see it.

Beat 0 — the loop. When a person corrects AI output, the edit is captured together with the prompt version that produced it. From those corrections the admin panel asks for a proposal — one real model call — and an operator accepts or rejects it. Nothing applies on its own. An accepted change becomes a new version on the ledger, and every run pins the version it used.

Beat 1 — the ledger is real. The git workflow the developers' AI follows went from v1 to v7 in five days as real deliveries taught us things. The reviewer skill was corrected twice after run S7-00009 misjudged colour contrast. Epic decomposition v2 was accepted from correction learning.

Beat 2. 82 recorded versions across 63 files, seven configuration layers, fourteen admin pages. Nothing about the system's own instructions changes silently.
