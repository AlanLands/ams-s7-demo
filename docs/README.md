# Documents — index

Reorganised and renamed 2026-09-03. Engineering documents that describe the
system as it is live at the top level of `docs/`; everything else sits in a
folder named for what it is. File names are plain kebab-case that say what
the document is — no `S7_` / `s7-` prefixes, since the whole repository is
S7. Rendered decks and PDFs are **dated deliverables**: each describes the
system as it stood on the day it was rendered and is not updated
retroactively, so check the date before quoting one.

## `design-history/` — dated plans and specs

`plans/` and `specs/` (formerly `docs/superpowers/`) hold the design and
implementation plans behind each feature, one pair per date, plus
`control-centre-implementation-plan-2026-08-07.md` (the original Control
Centre plan) and `intake-page-redesign-2026-08-09.md`. They record why things
are the way they are; the engineering docs above say what they are now.
Paths quoted inside them are as of their date and are not rewritten.

## Related, outside `docs/`

- `requirements/epics/` — the seeded epic (`EPIC-S7-001.md`) and change
  request the engine and tests read.
- `requirements/sample-documents/` — the synthetic MapleSure requirement PDFs
  (with their HTML sources) a presenter uploads at intake.

## Rendering

`demo/render_pdf.py <source.md|.html> <out.pdf>` renders any document here
with a local browser; `demo/render_leadership_deck.py` regenerates the
`.pptx`. Both are authoring tools and are not needed to run the demo.
